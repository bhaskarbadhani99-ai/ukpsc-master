UKPSC MASTER v1.0 – Starter PWA

Files:
- index.html: responsive quiz app and starter question bank
- manifest.json: install metadata
- sw.js: offline cache service worker
- icon.svg: app icon

Important:
1. A PWA must be hosted on an HTTPS origin for full Add to Home Screen / service-worker installation.
2. Upload these files preserving their folder structure to an HTTPS static host.
3. Open the hosted URL in Safari on iPhone > Share > Add to Home Screen.
4. Test history and wrong questions are stored locally in that browser/device. Clearing Safari website data may erase them.
5. This starter includes 25 sample questions. Review current affairs and changing official facts against official UK government/UKPSC sources.
